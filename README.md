# Supreme Calamitas — Brimstone Trial

Фанатська HTML-гра для ПК та телефона. Це не офіційний продукт Terraria або Calamity.

## Публікація на GitHub Pages

1. Увійди на https://github.com і створи **public** репозиторій `calamitas-bossfight`.
2. Завантаж у корінь репозиторію файли `index.html`, `version.json`, `.nojekyll` (README необов’язковий). Через GitHub можна перетягнути файли через Add file → Upload files.
3. У репозиторії відкрий Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
4. Вибери Branch: **main**, Folder: **/(root)** і натисни Save.
5. Після публікації сторінка доступна за адресою `https://ТВІЙ_НІК.github.io/calamitas-bossfight/`.

## Як працюють оновлення

Коли новий `index.html` потрапляє до гілки `main`, GitHub Pages автоматично публікує його за старим URL.

Під час **кожного релізу** також онови `version.json` (наприклад, `8.0.0` → `8.1.0`) **та** константу `currentVersion` в кінці `index.html` на ту саму версію. У грі є перевірка раз на 60 секунд і при поверненні до вкладки. Якщо версія змінилася, з'явиться кнопка оновлення. Поточний бій не перезавантажиться автоматично.

> Важливо: розмова в ChatGPT сама по собі не пушить файли в GitHub. Потрібен коміт або підключена інтеграція з дозволом на зміну репозиторію. Автоматичне розгортання працює **після** такого коміту.

## Примітка щодо приватності

З GitHub Free для публічного GitHub Pages репозиторій публічний, і будь-хто може переглядати гру та її вихідний код. Не додавай особисті дані, паролі або ключі API.
